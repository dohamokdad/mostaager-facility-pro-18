== Description ==

Mostaager Facility PRO Enterprise هو نظام إدارة مرافق متكامل على مستوى المؤسسات يجمع بين:
- إدارة الصيانة والفواتير من Mostaager Facility PRO
- استيراد متقدم مع WP All Import
- لوحة تحكم عربية احترافية
- تقارير متقدمة وتحليلات
- نظام أتمتة ذكي
- مراقبة في الوقت الفعلي
- تكاملات خارجية متقدمة

== Installation ==

1. ارفع مجلد الإضافة إلى /wp-content/plugins/
2. فعّل الإضافة من لوحة تحكم ووردبريس
3. اذهب إلى صفحة الإعدادات للتكوين
4. اتبع دليل التثبيت المفصل
